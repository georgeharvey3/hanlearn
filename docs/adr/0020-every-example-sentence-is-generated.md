# 20. Every example sentence is generated

- Status: accepted, amended (#482)
- Date: 2026-11-03
- Issue: #465, #478
- Amends: [0019-example-sentences-are-a-committed-build.md](0019-example-sentences-are-a-committed-build.md)

## Context

ADR 0019 made the example sentences a committed build, with Tatoeba and
Wiktionary as the input. Claude Code wrote sentences only for the HSK words
that the sources did not fill.

A review of the build output found that most source sentences were not
usable. Most Wiktionary entries were word glosses, not sentences. Many
Tatoeba sentences were very short or held foreign names. The generated
sentences did not have these faults.

## Decision

Every example sentence is generated by Claude Code and admitted by the
grader of the build. The build reads no other source.

The rest of ADR 0019 stays: the sentences are a committed build, with no
network and no AI at build time, and the id is a hash of the text.

## Consequences

- One grader and one prompt control every sentence.
- No sentence was written by a native speaker. A hand check of each
  generation batch is the only human review.
- A word outside HSK gets no sentences.
- More generation rounds are necessary: about 32,000 more sentences for the
  10,941 HSK words.
- The sentence files need no credit for each author.

## Alternatives

- Keep the sources with stronger filters. The filters cannot find every
  foreign name or every sentence with no context, and most Wiktionary
  entries fail any sentence filter.
- Keep Tatoeba only, with a filter, and generate the gaps. The set then
  has two quality standards.

## Amendment (2026-11-04)

- Issue: #482

The build reads Tatoeba again, but only sentences from native Mandarin
writers, with 6 or more Han characters and no names. These filters remove
the faults that the review of #473 found. Each sentence counts for every HSK
word that it holds. The target is 3 sentences for each word.

Generation was the only source after #478. It was too expensive to fill
every word, and HSK 1–3 lost almost all of its sentences.

The set now has two origins, `human` and `machine`. One grader admits both.
